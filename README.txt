VALTRIX BUSINESS MANAGER — PROTOTYPE v1

RUN IT
1. Download and extract this folder.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use VS Code Live Server.

INCLUDED
- Dashboard totals
- Product/service catalogue
- Sale entry
- Invoice preview and print-to-PDF

IMPORTANT LIMITATIONS
- This is a front-end prototype, not production-ready software.
- Data is stored only in this browser. It has no login, cloud database, multi-user accounts, backups, payment processing, or secure customer-data isolation.
- It starts with a sample service priced at ₹499. Replace it with an offer and price you can genuinely deliver before showing customers.
- Do not submit test records as real sales. Use actual transaction, customer, seller, date, and payment details.
- Before charging firms, add a secure backend/database, authentication, access controls, backups, privacy/security review, and relevant business/tax compliance.
